# Google Chat Admin bridge setup\n\n## Architecture\nWebsite user → Firebase Auth → Firestore → Apps Script bridge → Google Chat App/Space → Admin reply → Apps Script → Firestore → website user.\n\nGoogle Chat apps receive interaction events such as MESSAGE. For asynchronous messages outside the immediate interaction, the Chat API is used.\n\n## 1. Google Cloud / Chat App\n1. Create/select a Google Cloud project.\n2. Enable Google Chat API and Cloud Firestore API.\n3. Configure a Google Chat app using Apps Script.\n4. Create a Google Chat Space and add the Chat app.\n5. Copy the space resource name, for example spaces/AAA...\n\n## 2. Apps Script\nCreate a standalone Apps Script project and copy Code.gs and appsscript.json from this folder.\n\n## 3. Service account\nCreate a service account in the Google Cloud project. Keep its JSON private key OUT of GitHub. In Apps Script → Project Settings → Script Properties add:\n- CHAT_SERVICE_ACCOUNT_JSON = full JSON contents of the service-account key\n- GOOGLE_CHAT_SPACE = spaces/...\n- FIREBASE_PROJECT_ID = live-chat-5fb87\n- ALLOWED_ADMINS = ariful40807@gmail.com,fatema0063@gmail.com\n\nThe service account needs permission to send Chat messages and read/write the Firestore data used by this bridge.\n\n## 4. Deploy Web App\nApps Script → Deploy → New deployment → Web app. Copy the /exec URL.\n\nThen put the URL in index.html as GOOGLE_CHAT_BRIDGE_URL. The website will POST visitor messages to that bridge.\n\n## 5. Configure Chat callback\nIn Google Chat API configuration, connect the Apps Script deployment and enable MESSAGE events. The onMessage(event) function checks the approved admin emails, finds the website chat thread, and writes the reply to Firestore.\n\n## 6. Test\n1. Create a website account.\n2. Open Live Chat and send a message.\n3. A thread should appear in the configured Google Chat space.\n4. Reply in the same Chat thread.\n5. The reply should appear in the website chat.\n\n## Security\nNever put the service-account JSON/private key in the website or GitHub. Firebase Web API keys are not password-equivalent secrets; Firestore Security Rules and Authentication protect the client data.
